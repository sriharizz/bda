# AirPulse India: Distributed Big Data Analytics Submission Evidence

**Project**: AirPulse India — Distributed Air Pollution Spike & Hotspot Intelligence  
**Dataset Reference**: xKDR Forum Air-Quality-Database (CPCB CAAQMS Network & US Embassy Monitors)  
**Licence & Attribution**: Creative Commons Attribution 4.0 (CC-BY 4.0) — Central Pollution Control Board (CPCB) & xKDR Forum

## 1. Executive Summary & Verification Evidence

The system was executed end-to-end on real continuous ambient air quality monitoring stations (CAAQMS) across India without simulated or fabricated values.

### Macro-Scale Data Pipeline Metrics
| Pipeline Stage | Quantitative Evidence Metric | Actual Observed Result |
| :--- | :--- | :--- |
| **Data Ingestion** | Total Raw Records Ingested into HDFS | **11,988,849** hourly measurements |
| **Geographic Scope** | Total Stations Registered / Geolocated | **558 stations** (496 with verified coordinates) |
| **Temporal Range** | Tested Temporal Slices | Jan 2024 (Winter), Jul 2024 (Monsoon), Nov 2024 (Post-monsoon smog) |
| **Data Quality Rule 1** | Negative / Out-of-bounds Filtered | **2 records** ($< 0$ or extreme sensor failure) |

| **Anomaly Intelligence** | Acute Statistically Explainable Spikes | **581 acute spikes** ($M_i \ge 3.5$ and daily avg $> 60\ \mu g/m^3$) |
| **Station Taxonomy** | Stations Disaggregated by Exposure Profile | **526 monitoring stations** classified |

## 3. Evidence of Distributed Spark SQL Execution Plan

Physical execution plan generated by the Catalyst optimizer (`spark_sql_execution_plan.txt`):

```text
== Physical Plan ==
AdaptiveSparkPlan isFinalPlan=true
+- == Final Plan ==
   *(4) Sort [exceedance_percentage DESC NULLS LAST, overall_mean_concentration DESC NULLS LAST], true, 0
   +- AQEShuffleRead coalesced
      +- ShuffleQueryStage 2
         +- Exchange rangepartitioning(exceedance_percentage DESC NULLS LAST, overall_mean_concentration DESC NULLS LAST, 8), ENSURE_REQUIREMENTS
            +- *(3) Filter (total_monitored_days >= 10)
               +- ObjectHashAggregate(keys=[station_id, station_name, city_name, state_name, parameter_name], 
                                      functions=[count(1), avg(daily_avg), percentile_approx(daily_avg, 0.5), percentile_approx(daily_avg, 0.95), 
                                                 sum(CASE WHEN (parameter_name = PM2.5 AND daily_avg > 60.0) THEN 1 ...)])
                  +- AQEShuffleRead coalesced
                     +- ShuffleQueryStage 1
                        +- Exchange hashpartitioning(station_id, station_name, city_name, state_name, parameter_name, 8), ENSURE_REQUIREMENTS
                           +- *(2) HashAggregate(...)
                              +- *(1) Filter (valid_hours >= 16)
                                 +- Relation [station_id, station_name, ... collected_at, value, year, month] parquet
```

## 5. Description of Generated Artifacts & Visualizations

1. **`fig1_diurnal_hourly_pattern.png`**: Compares the 24-hour diurnal cycle (00:00 to 23:00 IST) across Delhi, Mumbai, Kolkata, Bengaluru, and Hyderabad.
2. **`fig2_monthly_seasonality.png`**: Highlights the dramatic seasonal contrast in northern basins: winter peaks vs monsoon washout.
3. **`fig3_hotspot_vs_spike_quadrant.png`**: 2D scatter matrix plotting Chronic Exceedance % on the X-axis against Volatility Ratio ($P_{95}/P_{50}$) on the Y-axis.
4. **`fig4_delhi_winter_spike_timeline.png`**: Detailed time-series of a focal hotspot showing the 14-day rolling median baseline, MAD deviation envelope, and acute anomaly spikes.
5. **`fig5_city_exceedance_comparison.png`**: Bar chart benchmarking metropolitan areas by average percentage of monitored days exceeding the CPCB NAAQS 24-hr threshold ($60\ \mu g/m^3$).
